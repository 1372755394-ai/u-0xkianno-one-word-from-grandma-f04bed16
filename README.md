One word, and nothing else: **computor** — the single word Grandma would text about AI. It is the classic grandma typo for "computer": warm, a little baffled, funny in one word, and unmistakably about the machine. No sentence, no explanation, no punctuation tricks.

## Run it

```sh
python3 main.py
```

`main.py` uses only the Python standard library. It validates the word against the gate (UTF-8 text, 1–30 characters, exactly one non-blank word) and writes it to `/output/entry.txt` (`MAKEFUN_OUTPUT_PATH` overrides the path for local runs).
